# Хардкодинг PRO · Агент и Google Таблицы

Набор после эфира «Агент и таблицы». Ваш ИИ-агент (Claude Code, Codex или ZCode) сам подключит Google Таблицы:
задаст пару вопросов, выберет способ, почти всё настроит сам и докажет, что умеет читать и записывать.

## Как пользоваться

Откройте агента в рабочем режиме (не в обычном чате) и отправьте ему фразу:

```
Зайди на https://github.com/PavelDumbrao/hardcoding-sheets-kit, прочитай файл PROMPT.md и выполни его как моё задание. Начни с вопросов ко мне.
```

Если агент не открывает GitHub, дайте ему прямую ссылку на текст:
https://raw.githubusercontent.com/PavelDumbrao/hardcoding-sheets-kit/main/PROMPT.md

Или скопируйте текст из [PROMPT.md](PROMPT.md) и вставьте агенту сами.

## Какие способы подключения знает агент

| Способ | Что делаете вы | Читает / пишет | Работает без вас |
|---|---|---|---|
| А. Коннектор Google Drive | Один вход в Google по кнопке | читает, создаёт файлы | нет |
| Б. Почта агента (сервисный аккаунт) | Входите по ссылке и делитесь таблицей | да / да | да |
| В. Мост через Apps Script | Вставляете скрипт в таблицу, жмёте «Развернуть» | да / да | да |
| Г. Ссылка только для чтения | Открываете доступ по ссылке (только без личных данных) | да / нет | да |
| Д. Файлом | Скачиваете таблицу в папку проекта | да / в новый файл | нет |

## Безопасность

- Ключи и пароли агенту в чат не вставляйте: он сам скажет, в какую папку их положить.
- Делитесь с агентом одной таблицей, а не всем Диском.
- Таблицу с именами, телефонами и деньгами клиентов никогда не открывайте «по ссылке для всех».
- Забрать доступ: уберите почту агента из «Поделиться» в таблице.
